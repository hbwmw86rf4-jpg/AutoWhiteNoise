# AutoWhiteNoise

White-noise and sleep-sound app for iPhone, iPad and Mac that can be started by schedules, Shortcuts
automations, another family member's phone, and smart-home devices on the same Wi-Fi.

Status: planning. Start with `docs/01-what-apple-allows.md` (platform constraints, researched) and
`docs/02-plan.md` (architecture, phases, open questions).
